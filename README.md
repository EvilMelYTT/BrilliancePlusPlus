# Brilliance

This mod allows a player to toggle Night Vision to see in the dark!

---

### Supported Versions
- 26.1.x
- 1.21.11
- 1.21.2
- 1.21.1
- 1.21
- 1.20.4

**Support for this project will be reinstated for as long as I remember this exists**

---

### Features

/nightvision to toggle night vision.
Press "N" to toggle night vision.
**Change the keybind for night vision in the game options!**
